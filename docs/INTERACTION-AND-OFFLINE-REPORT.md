# Interaction, search, scanner review and offline increment

Local development only, 21 October 2026. No commit, push, deployment, production-data operation or cloud configuration change.

## Daily-use UI

- Home shortcuts are a horizontally scrollable row: Explore, Queue, Disk Map, Locations and Fix mismatches. Library defaults to All. Explore is a separate Home destination, without a Library tab. Watchlist was removed from More/settings. Disk Map opens Toshiba (E:) by default, with a horizontal selector for E: Toshiba (4TB), F: Legion (1TB) and G: Seagate (1TB). Its button genuinely toggles the selector without clearing the selected drive. The disk selector contains only disks; duplicate cards, Queue and Unmapped entries were removed.
- Home search retains an inline field beneath the header. Results are grouped as In Library and Not In Library. The inner duplicate focus ring is removed. The redundant header Add icon is removed; Add manually opens the compact form directly and preserves the entered title. Add dialogs have a translucent frosted background.
- Connected search loads library results independently of slower metadata results. It accepts IMDb IDs and IMDb title URLs, resolves provider identities (including renamed titles), distinguishes movie and TV IDs and sends archived matches to Trash instead of encouraging duplicate imports. Cancellation/generation guards prevent stale query results. Owner-only `/api/search` and local IMDb matching are covered by fixtures. The preview does not fake a live TMDb feed.
- Title toolbar now preserves the top safe area instead of subtracting it from the page margin. Back, Favorite and More retain at least 44px targets. Glance season controls fit full labels. Date controls have explicit shrinkable dimensions to address Safari intrinsic-width overflow. Episode rows and labels are larger.
- The title progress bar is a keyboard/touch slider. Release applies the selected season in one local persistence operation; Undo restores the complete previous event set. Existing dates and other seasons/titles are preserved. Invalid and unreleased targets are rejected. The connected private diary still needs a corresponding bulk-progress API before this slider is carried into that workspace.
- Collection List view was removed. The selection icon is in the upper toolbar; a 450ms hold also enters selection with the held title selected. Scrolling, pointer cancellation and release before the threshold cancel the hold. Library artwork carries distinct coloured status icons in its bottom-right corner, with a dark contrast backing and accessible status text.
- Queue is an explicit, independent download reminder (`queued`, migration `0005_late_sumo.sql`). Single-title menus and bulk selection support adding and removing Queue without changing watch status, history or file mappings. Old saved previews default to an empty Queue rather than automatically treating Planned titles as downloads. The existing `disk=downloads` URL remains compatible with the Queue filter.
- Episode rows share an aligned grid, consistent border/padding and taller artwork. Synopses are collapsed by default; tapping anywhere on a row expands/collapses its full-width synopsis below the artwork/title row. The watch checkmark stays independently clickable. Opening one unwatched preview row reveals only that episode; the private diary requests one episode through the existing owner-guarded season endpoint and merges only its metadata.
- The title toolbar now creates a stacking layer above hero content. More menus have a strong frosted backing and bounded scrolling; synopsis/rating text cannot paint over their options.
- Glance/Continue backdrops open the same title as their poster. Foreground controls remain independent. Episodes, Notes and Files shortcuts reveal their target before a reduced-motion-aware smooth scroll.
- Page navigation shows the centered spinning brand for a minimum of about 400ms, followed by a fade. Content uses a small transform/opacity entrance without moving the fixed shell. Larger circular nav indicators have a brief selection pulse. Normal browser back navigation is restored: the four-swipe limit and session lock were removed, and main tabs create ordinary history entries. Section links still replace same-title hash entries. Native physical-iPhone gestures still need owner validation.
- Successful watched/progress/completed/watchlist/favorite changes produce a short, brighter confetti burst at the originating control. Decorative particles are clipped in a viewport overlay and cannot intercept input or cause page overflow. Unlike/undo do not celebrate. Reduced motion suppresses decorative effects. Normal notifications expire after 2 seconds; Undo notifications after 4 seconds.
- Trash has direct Empty Trash and per-title Delete controls. Selected Trash deletions bypass the review dialog and no typed DELETE field remains. The owner explicitly requested these one-step actions. Backend owner/origin guards and explicit machine action bodies remain. Deletion is limited to archived diary records and linked diary data, not disk files. No permanent deletion was performed through browser QA.

## Scanner review foundation

Migration `0004_happy_darkstar.sql` adds an unmatched-scans queue outside the library. Owner-only paged reads show unresolved folders, PC/drive/path, season hints and file counts. Resolution accepts an existing title identity or an explicitly reviewed metadata import, then atomically maps the folder and resolves its versioned queue record. Stale or archived targets cannot partially mutate the mapping. Existing history remains unchanged. Tests exercise rollback and authentication boundaries.

The local preview honestly shows Scanner not connected. Windows scanner pairing, upload ingestion and automatic matching are still Phase 3 work; this increment does not claim to have scanned the owner's PC or to have a live queue already.

## Device caching and offline scope

The production service worker precaches generated code with four concurrent requests, caches bounded shipped sample artwork, and uses a generated data-free CSR shell for offline `/preview` navigation. Normal preview navigation remains network-first; 401/403 responses are never replaced by cached HTML. Private SSR pages, owner API responses, auth pages, query-token assets and redirected/HTML asset responses are excluded. Old cache cleanup touches only this app's asset prefix and never IndexedDB.

Preview episode changes already persist to a separate IndexedDB workspace. A Safari LAN-HTTP failure in `crypto.randomUUID` was corrected with a cryptographically random UUID fallback. Real authenticated offline data synchronization is not implemented by this public-asset cache. iPhone service workers require HTTPS; a plain PC LAN HTTP preview cannot validate installed/offline PWA behavior.
