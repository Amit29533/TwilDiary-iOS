# Library reference with native selectors

The Library uses the supplied B1/B2 references with the user's subsequent corrections: compact underlined All / Movies / Shows / Anime tabs, a horizontal native selector row, three poster columns on phones, two-line labels, progress strips, and a restrained dark plum palette. Existing artwork remains; missing Library artwork uses deterministic colored initials. Styling is scoped to Library and opt-in card props.

- Status, Genre, Disk and sorting use real HTML `select` controls, so iPhone shows its native system selector. No custom popover, genre search, Views chip or Group chip remains. Genre stays a single native choice.
- Status retains Planned, Watching, Completed, Dropped and independent Queue download reminders. Disk retains drive shortcuts, exact physical volume links and No disk mapping. Existing Home Disk Map links filter the same native Disk selector.
- The Trash chip sits directly after Disk and toggles back to Library when active. Trash retains its Empty Trash action and per-title restore/permanent-delete controls. Long press on a poster opens existing bulk selection. The ellipsis menu was removed at the user’s request and replaced by the prior Browse by genre button. Existing Favorites/location/tag deep links and Clear filters still work.
- The layout button switches grid/list. Sort/layout/filter parameters and existing per-page memory remain wired. Clearing filters retains layout. The restored genre button toggles genre shelves; See all opens the matching genre grid. No Group chip is shown.
- The category row is reduced to 40px with tighter horizontal/vertical padding; mobile Library top padding is 2px. Native filter controls are whole-chip tap targets. No custom popup can cover content or intercept back navigation. Library order has no resting border or background. Focus adds one rounded highlight around the whole control, rather than an outline on its inner select.
- Poster progress counts distinct regular episodes or an active movie watch, rather than counting rewatches twice. Revoked logs and specials do not contribute to regular series progress. Personal ratings stay visible; completed titles use a compact green check. Standard poster dimensions and Glance remain unchanged.

Verification includes existing library/Queue/link tests, progress regression tests, Svelte/TypeScript checks, production build and compiled PWA checks. No database migration or owner-history writes are needed. Browser visual automation is unavailable; native iPhone menu appearance requires physical-device review.
