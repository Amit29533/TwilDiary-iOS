# Home reference follow-up

The user selected the layout: preserve the existing header, continue-watching carousel and shortcuts; place This week, Up next and New episodes below the shortcuts; keep Recently watched farther down. The existing compact history rows and All history destination remain in use. The old unbounded For your next evening grid is replaced by the compact Up next section.

`HomeSections.svelte` uses a muted plum panel palette inspired by the supplied Home reference, without changing global tokens or the protected upper Home design. It contains:

- This week: runtime estimate, movie/episode watch count, current streak, and seven Monday–Sunday calendar cells. The same `diaryStats` calculation drives Stats and this summary. Future days are disabled; an active day opens the corresponding date-filtered history. Stats opens the existing Stats tab.
- Up next: a three-poster preview from unwatched Planned titles and a Pick for me action using the existing random-pick dialog with only that same eligible pool. Planned opens the complete filtered Library. No watch, status or Queue mutation is performed by selecting a suggestion.
- New episodes: the next unwatched regular episode per non-dropped library series, due today or within the following 30 calendar days, ordered by air date. Specials, skipped/watched episodes, unknown or invalid dates, movies and trashed/dropped titles are excluded. The list expands with Show more and retains its limit on return. Links open the title's requested season and episode section. Episode names/synopses are not revealed in these rows.

Upcoming episodes are based on saved library episode dates; this view does not silently claim a fresh provider schedule. Missing schedules show a clear empty state. The footer notes that air dates may change. Watch time remains an estimate from known title runtimes; missing dates/runtime are not invented.

`domain/home.ts` is pure and uses local-calendar day arithmetic from Stats. Four fixture tests verify matching weekly totals, the Planned pool, nearest-per-show eligibility and filtering, immutable input, New Year rollover and DST. The full release passes 300 unit/database/runtime tests, 3 compiled PWA checks, production build, and zero Svelte/TypeScript errors or warnings. No database migrations, owner-history writes, commits or pushes were performed. Browser visual automation was unavailable; phone appearance remains unverified by the agent.

The Pick up where you left off carousel now shares Glance's active-season progress and remaining-time calculation. Its compact line uses `S1 · E11 of 16 · 4h 40m left`, with the same soft grey remaining-time color and dark readability shadow. Missing metadata/runtime shows Time unknown. Only the visible carousel card requests missing season metadata, and its plus button logs the exact episode shown by the shared helper. Existing carousel dimensions, art, progress bar, and scrolling behavior are retained.

The pickup carousel no longer shows a favorite heart. After physical iPhone feedback about blurred lettering and artwork showing behind the controls, the shared app header uses a solid background with no blur or fade mask. Header text is a normal inline run instead of separately animated letters. Compact header spacing and controls retain their positions.

Physical iPhone measurements confirmed the current styles had no CSS blur/mask/transform on the header or its ancestors, a 59px safe area, and an active 59px fixed opaque surface. Both 1px and safe-area surfaces failed to suppress the iOS 27 Home Screen overlay. Those surfaces and the temporary local diagnostics were removed. A 24px clearance workaround was tried locally, but the user rejected its lower position. The original compact header and title/person toolbar positions are restored, with no extra clearance. The system blur remains unresolved; do not reintroduce that extra gap. The user chose to defer further blur work until the Capacitor/iOS IPA stage.
