# Title detail redesign

Applies the supplied references to shows, anime, movies and anime movies, including the matching online catalogue screens. The final user steering restores the original sharp full-strength backdrop and 114px phone poster, with name, metadata, gold TMDb score, purple personal-rating control and collapsed overview alongside the poster. Expanded overview flows beside the poster and then below it. Normal art has no blur, filter or opacity dimming; only a bottom fade blends into the page. Top toolbar buttons retain their original safe-area position and stay pinned while scrolling. The iOS 27 system-header blur investigation remains deferred to Capacitor.

The progress card contains the native watch-status selector, remaining time, selected-season counts, segmented accessible range input, spoiler-aware Up next preview and a normal purple watch button. The watched action stays inside the card and has no dropdown. Date and title-level rating controls remain separate, labelled Watched today and Rate show / Rate movie. Controls use shrinking grid tracks and bounded date input sizing to avoid iPhone overflow. Server availability appears only in the existing location disclosure below Notes; there is no duplicate chip under the watch button.

Season tabs and season text were removed from the progress card. A native iOS season selector sits beside Episodes. The compact episode list shows four ordered entries around the next episode with Show all for longer seasons. Existing spoiler reveal, community episode scores, air-date restrictions, retry notices, view memory and watch/status Undo behaviour remain. Cast follows Episodes, then You might like, followed by the combined Notes / On your drives card. Movies have the same section order after their watch panel, with no episode section.

The top-right ellipsis uses an actual native select on title detail pages. The top menu contains Queue, Notes and File locations. Episodes/Watch logger, Your rating and Move to Trash were removed from this menu at the user's request. Other cards retain their current menu. Native selector navigation and normal section links share the same reveal-before-scroll function.

Movies show their active viewing count and binary 0/100 slider, watched date, Rate movie and Log a watch / Log a rewatch. Returning the slider to zero removes only the latest viewing, preserving the agreed history behaviour.

Selected-season counts use the larger of loaded episodes and the manifest count. Time estimates and season range edits are withheld while metadata is incomplete. Rewatches do not inflate episode counts and unrelated or revoked watches do not count. Unknown runtimes remain unknown. Notes retain explicit Save notes and a Saved indicator. Notes and locations start collapsed; explicit menu/deep links open their target, and return navigation still remembers user expansion. The location summary says Available on Server: Drive … using sorted, deduplicated actual confirmed drive letters across the title's seasons, or Not Available on Server when no copy is currently confirmed present. Expanding it shows full mapped paths, file/device details and the original offline/unverified evidence; it does not erase uncertain or missing mappings. File availability comes from mapped evidence, never fabricated reference values.

Validation: 317 unit/domain/API tests and 3 compiled service-worker tests passed for the redesign. Final selector/layout verification is recorded in `.local/title-availability-verify.log`. Physical iPhone appearance and native menu presentation require user review.
